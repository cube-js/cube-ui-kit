# NavTabs

Navigation between routes that looks like [Tabs](/docs/navigation-tabs--docs). It renders a navigation landmark holding a list of real links, and marks the link for the current page with `aria-current="page"`. Each link goes through the app's navigation adapter, as a `Button`'s `to` does, so a click routes in the app, and the browser's own link features keep working: a modified or middle click opens a new tab, the context menu has "Copy link", and the URL shows on hover.

## When to Use

- The items lead to different routes or pages, each with its own URL, such as the sections of a settings or detail page.
- You want the look of `Tabs` for that navigation, at any width.
- Use [Tabs](/docs/navigation-tabs--docs) instead when the items switch content in place: a tab always opens its own panel, and never leaves the page.

### Properties

- **`label`** `string` — Accessible name of the navigation landmark, such as the area it moves between. Required: a page with several navigation landmarks tells them apart by name.
- **`activeKey`** `string` — Key of the item for the current page. A sub-page passes its section's key, so the section stays current.
- **`placement`** `'top' | 'bottom' | 'left' | 'right'` (default: `'top'`) — Where the strip sits: `top` / `bottom` keep it horizontal, `left` / `right` make it vertical.
- **`tabListPadding`** `string` — Inline padding for the item list (e.g. `"2x"` → `0 2x`), as on `Tabs`.
- **`children`** `ReactNode` — `NavTabs.Item` elements, each with a React `key`.

### NavTabs.Item Properties

- **`to`** `To` — Where the item leads: a path or a `{ pathname, search, hash }` object, resolved by `Root`'s `navigation` adapter.
- **`children`** `ReactNode` — The item's label. Optional for an icon-only item.
- **`icon`** `ReactNode` — An icon before the label.
- **`aria-label`** `string` — The accessible name of an icon-only item.
- **`tooltip`** — A tooltip, as on `Item`. A label that doesn't fit is truncated and shown in a tooltip by default.
- **`isDisabled`** `boolean` — A disabled item leads nowhere: it has no `href` and can't be activated.
- **`qa`** `string` (default: `NavTab-<key>`) — QA selector.

## Examples

### With a Router

`activeKey` comes from the current route, here a route parameter. Items take the same destinations as the rest of the app's links.

```jsx
const { tenantId, section } = useParams();

<NavTabs label="Tenant" activeKey={section}>
  <NavTabs.Item key="profile" to={`/tenants/${tenantId}/profile`}>
    Profile
  </NavTabs.Item>
  <NavTabs.Item key="users" to={`/tenants/${tenantId}/users`}>
    Users
  </NavTabs.Item>
  <NavTabs.Item key="groups" to={`/tenants/${tenantId}/groups`}>
    Groups
  </NavTabs.Item>
</NavTabs>;
```

### Sub-pages

A sub-page, such as one user's page under Users, keeps its section current: pass the section's key, not the page's.

```jsx
// Matches `/tenants/42/users` and `/tenants/42/users/7` alike.
const section = SECTIONS.find((key) =>
  pathname.startsWith(`${basePath}/${key}`),
);

<NavTabs label="Tenant" activeKey={section}>
  …
</NavTabs>;
```

## Accessibility

### Keyboard Navigation

- `Tab` / `Shift+Tab` - Move between the links, like any links on the page
- `Enter` - Follows the focused link

Arrow keys don't move between items: that is the `Tabs` pattern, for content that switches in place.

### Screen Reader Support

- The strip announces as a navigation landmark named by `label`, holding a list
- Each item announces as a link; the current one as the current page
- A disabled item announces as a dimmed button

### ARIA Properties

- `aria-label` - Set via `label` on the `nav` element
- `aria-current="page"` - On the item `activeKey` names

## Best Practices

1. **Do**: Use `NavTabs` when each item is its own route

   ```jsx
   <NavTabs label="Billing" activeKey={section}>
     <NavTabs.Item key="overview" to="/billing/overview">
       Overview
     </NavTabs.Item>
     <NavTabs.Item key="usage" to="/billing/usage">
       Usage
     </NavTabs.Item>
   </NavTabs>
   ```

2. **Don't**: Use `NavTabs` to switch content within a page; use `Tabs`, which links each tab to its panel

3. **Do**: Name each navigation landmark, so a page with several tells them apart
