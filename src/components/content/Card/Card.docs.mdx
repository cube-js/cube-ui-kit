# Card

A container with rounded corners, border, and padding. Renders as a `<div role="region">`.

## When to Use

- Grouping related information
- Content containers in dashboards
- Highlighting standalone content blocks

## Properties

- **`isQueryContainer`** `boolean` (default: `false`) — Makes the card the `card` query container (`container: card / inline-size`), so its content can respond to its width: `@(card, w < 400px)` in `styles`, or `collapseState` on a `Button`. See [Query container](#query-container)

### Style Defaults

- `display` — `block`
- `flow` — `column`
- `radius` — `(1cr + 1bw)`
- `fill` — `#surface`
- `border` — `#border`
- `padding` — `1.5x`
- `preset` — `t3`

### Base Properties

Supports [Base properties](/docs/getting-started-base-properties--docs).

### Style Properties

These properties allow direct style application without using the `styles` prop:

- **Base:** `display`, `font`, `preset`, `hide`, `whiteSpace`, `opacity`, `transition`
- **Position:** `gridArea`, `order`, `gridColumn`, `gridRow`, `placeSelf`, `alignSelf`, `justifySelf`, `zIndex`, `margin`, `blockMargin`, `inlineMargin`, `inset`, `blockInset`, `inlineInset`, `position`, `scrollMargin`, `blockScrollMargin`, `inlineScrollMargin`, `scrollPadding`, `blockScrollPadding`, `inlineScrollPadding`
- **Dimension:** `width`, `height`, `blockSize`, `inlineSize`, `flexBasis`, `flexGrow`, `flexShrink`, `flex`
- **Block:** `border`, `blockBorder`, `inlineBorder`, `radius`, `shadow`, `outline`, `padding`, `blockPadding`, `inlinePadding`, `overflow`, `scrollbar`, `textAlign`
- **Color:** `color`, `fill`, `fade`, `image`
- **Flow:** `flow`, `place`, `placeItems`, `placeContent`, `alignItems`, `alignContent`, `justifyItems`, `justifyContent`, `align`, `justify`, `gap`, `columnGap`, `rowGap`, `gridColumns`, `gridRows`, `gridTemplate`, `gridAreas`

## Examples

```jsx
<Card>
  <Title level={3}>Card Title</Title>
  <Paragraph>Card content goes here.</Paragraph>
</Card>

<Card padding="2x" fill="#surface">
  Styled card with custom padding and background
</Card>
```

### Query container

With `isQueryContainer`, the card is the `card` container, so a button in it can collapse while the card is narrow:

```jsx
<Card isQueryContainer>
  <Button icon={<IconShare />} collapseState="@(card, w < 400px)">
    Share
  </Button>
</Card>
```

A query container ignores its content's width, so set the prop only on a card whose width comes from outside: a block, an item a flex column or grid stretches, or a set `width`. A card sized by its content, in a horizontal `Space`, centered, or with `width="max-content"`, would shrink to its padding. Without the prop, a card's `@(card, …)` condition finds no container, and the button keeps its full look.
