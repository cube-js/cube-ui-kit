# Result

An empty state or result display with icon, title, and optional content. Supports status presets with built-in icons, a prominent value, and an actions slot. The `large` size turns it into the vertical card used as the body of a confirmation or result dialog.

## When to Use

- Empty states (no data, no results)
- Success/error feedback after actions
- Confirmation and result dialogs (payment complete, action failed)
- 404, 403, 500 error pages
- Informational messages

### Properties

- **`status`** `'success' | 'error' | 'info' | 'warning' | 404 | 403 | 500` (default: `'info'`) — Predefined status with corresponding icon
- **`title`** `ReactNode` — Main title text
- **`value`** `ReactNode` — Prominent value between the title and the subtitle, e.g. an amount with currency
- **`subtitle`** `ReactNode` — Secondary text below the title
- **`subTitle`** `ReactNode` — Deprecated: use `subtitle` instead
- **`icon`** `ReactNode` — Custom icon that replaces the status icon
- **`size`** `'medium' | 'large'` (default: `'medium'`) — Visual scale. `large` is the dialog card: bigger icon and title, stacked full-width actions
- **`isCompact`** `boolean` (default: `false`) — Compact horizontal layout
- **`actions`** `ReactNode` — Action buttons: a centered row by default, a stacked full-width column in the `large` size
- **`children`** `ReactNode` — Free content between the text and the actions

The elements render in this order: icon, title, value, subtitle, children, actions.

### Base Properties

Supports [Base properties](/docs/getting-started-base-properties--docs).

### Styling Properties

#### styles

Customizes the root element of the component.

**Sub-elements:**

- `Icon` - The status icon wrapper. Colored by the `status` modifier. Not rendered when a custom `icon` is passed
- `Title` - The text block holding the title, the value and the subtitle
- `Value` - The prominent value. Uses tabular figures so amounts do not shift width
- `Content` - The free `children` block
- `Actions` - The `actions` block

### Style Defaults

- `display` — `flex` (switches to `grid` when `isCompact`)
- `flow` — `column`
- `placeContent` — `center` (switches to `start` when `isCompact`)
- `placeItems` — `center` (switches to `start` when `isCompact`)
- `gap` — `3x` (switches to `2x 1x` when `isCompact`)
- `padding` — `6x 4x` (`0` when `isCompact`, `3x 1x` when `size="large"`)
- `textAlign` — `center` (switches to `left` when `isCompact`)
- `width` — `max 80ch` (caps the readable line length; override via the `width` prop)
- `margin` — `0 auto` (centers Result horizontally within its parent; switches to `0` when `isCompact`)
- `--icon-size` — `6x` (`10x` when `size="large"`)

### Modifiers

The root element exposes these modifiers as `data-*` attributes:

| Modifier  | Type                  | Description                                        |
| --------- | --------------------- | -------------------------------------------------- |
| `compact` | `boolean`             | Set by `isCompact`: horizontal icon + title layout |
| `size`    | `'medium' \| 'large'` | Set by `size`                                      |
| `status`  | `CubeResultStatus`    | Set by `status`; drives the icon color             |

## Sizes

- `medium` - Default. Icon `6x`, title `h4`, subtitle `t2m`, value `h2`, actions in a centered row
- `large` - The dialog card. Icon `10x`, title `h2`, subtitle `t2` in `#dark-02`, value `h1`, actions stacked to the full width. Pass `size="large"` to the buttons to match

### Large

The `large` size is the vertical card for confirmation and result dialogs.

```jsx
<Result
  size="large"
  status="success"
  title="Payment complete"
  value="$1,234.00"
  subtitle="Charged to Visa **** 4242"

      Done
    </Button>
  }
/>
```

<Canvas of={ResultStories.Large} />

Show a value only where money moved. A failed or unknown result leaves it out, so a large amount never reads as a charge that did not happen. Free `children` (an alert, details) stretch to the full width in this size.

<Canvas of={ResultStories.LargeStatuses} />

### In a Dialog

Inside a `Dialog` the `large` Result is the whole body: no `Header` and no `Footer`. Its title takes the dialog `title` slot, so the dialog is labelled by it automatically.

```jsx
<DialogContainer isOpen={isOpen} onDismiss={close}>
  <Dialog size="S">
    <Content>
      <Result
        size="large"
        status="success"
        title="Payment complete"
        value="$1,234.00"
        subtitle="Charged to Visa **** 4242"
        actions={
          <Button type="primary" size="large" onPress={close}>
            Done
          </Button>
        }
      />
    </Content>
  </Dialog>
</DialogContainer>
```

## Accessibility

### Screen Reader Support

- The title renders as an `h2` heading and the subtitle as an `h3`, so the result is reachable through heading navigation
- Inside a `Dialog` without a `Header`, the title takes the dialog's `title` slot and becomes its accessible name

### Keyboard Navigation

- The component itself is not focusable; the buttons passed through `actions` keep their own keyboard behavior

## Best Practices

1. **Do**: Put the buttons in `actions` and keep `children` for content

   ```jsx
   <Result title="Payment failed" actions={<Button>Update card</Button>}>
     <Alert>Nothing was charged.</Alert>
   </Result>
   ```

2. **Don't**: Combine a `large` Result with a dialog `Header`. Both titles would take the dialog `title` slot and share one id

   ```jsx
   <Dialog>
     <Header>
       <Title>Payment</Title>
     </Header>
     <Content>
       <Result size="large" title="Payment complete" />
     </Content>
   </Dialog>
   ```

3. **Value**: Show it only where the number is the outcome. Leave it out of a failed or uncertain result
