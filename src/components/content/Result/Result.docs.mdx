# Result

An empty state or result display with icon, title, and optional content. Supports status presets with built-in icons and an actions slot. The `large` size with the `stacked` layout is the vertical card used as the body of a confirmation or result dialog.

## When to Use

- Empty states (no data, no results)
- Success/error feedback after actions
- Confirmation and result dialogs (payment complete, action failed)
- 404, 403, 500 error pages
- Informational messages

### Properties

- **`status`** `'success' | 'error' | 'info' | 'warning' | 404 | 403 | 500` (default: `'info'`) — Predefined status with corresponding icon
- **`title`** `ReactNode` — Main title text
- **`subtitle`** `ReactNode` — Secondary text below the title
- **`subTitle`** `ReactNode` — Deprecated: use `subtitle` instead
- **`icon`** `ReactNode` — Custom icon that replaces the status icon
- **`size`** `'medium' | 'large'` (default: `'medium'`) — Visual scale: the icon size and the title and subtitle presets. Does not change the layout. Ignored when `isCompact` is set
- **`layout`** `'default' | 'stacked'` (default: `'default'`) — Arrangement of the block. `stacked` fills the container and stacks the actions to the full width, as in a confirmation or result dialog. Ignored when `isCompact` is set
- **`isCompact`** `boolean` (default: `false`) — Compact horizontal layout. Overrides `size` and `layout`
- **`actions`** `ReactNode` — Action buttons: a centered row by default, a full-width column in the `stacked` layout
- **`children`** `ReactNode` — Free content between the text and the actions

The elements render in this order: icon, title, subtitle, children, actions.

### Styling Properties

#### styles

Customizes the root element of the component.

**Sub-elements:**

- `Icon` - The status icon wrapper. Colored by the `status` modifier. Not rendered when a custom `icon` is passed
- `Title` - The text block holding the title and the subtitle
- `Content` - The free `children` block
- `Actions` - The `actions` block

### Style Defaults

- `display` — `flex` (switches to `grid` when `isCompact`)
- `flow` — `column`
- `placeContent` — `center` (switches to `start` when `isCompact`)
- `placeItems` — `center` (switches to `start` when `isCompact`)
- `gap` — `3x` (switches to `2x 1x` when `isCompact`)
- `padding` — `6x 4x` (`0` when `isCompact` or `layout="stacked"`: the host pads, e.g. a dialog `Content`)
- `textAlign` — `center` (switches to `left` when `isCompact`)
- `boxSizing` — `border-box`
- `width` — `max 80ch` (caps the readable line length; override via the `width` prop). `100%` up to `80ch` when `layout="stacked"`, so the stacked actions share one width wherever the card sits
- `margin` — `0 auto` (centers Result horizontally within its parent; switches to `0` when `isCompact`)
- `--icon-size` — `6x` (`10x` when `size="large"`)

### Modifiers

The root element exposes these modifiers as `data-*` attributes:

| Modifier | Type | Description |
| --- | --- | --- |
| `compact` | `boolean` | Set by `isCompact`: horizontal icon + title layout |
| `size` | `'medium' \| 'large'` | Set by `size`; `medium` when `isCompact` |
| `layout` | `'default' \| 'stacked'` | Set by `layout`; `default` when `isCompact` |
| `status` | `CubeResultStatus` | Set by `status`; drives the icon color |

## Variants

### Sizes

The size scales the content and never changes the arrangement. `isCompact` has its own scale and ignores it.

- `medium` - Default. Icon `6x`, title `h4`, subtitle `t2m`
- `large` - Icon `10x`, title `h2`, subtitle `t2`. Pass `size="large"` to the buttons to match

### Layouts

The layout arranges the block and never changes the scale. `isCompact` has its own arrangement and ignores it.

- `default` - A centered column capped at `80ch`, actions in a centered row that wraps
- `stacked` - Fills the container up to `80ch` with no padding of its own, actions stacked to the full width, free `children` stretched. Combine with `size="large"` for the vertical card of a confirmation or result dialog

### Stacked

The `stacked` layout fills the container and stacks the actions to the full width. With `size="large"` it is the vertical card for confirmation and result dialogs.

```jsx
<Result
  size="large"
  layout="stacked"
  status="success"
  title="Payment complete"
  subtitle="Charged $1,234.00 to Visa **** 4242"
  actions={
    <Button type="primary" size="large">
      Done
    </Button>
  }
/>
```

Free `children` (an alert, details) stretch to the full width in this layout.

<Canvas of={ResultStories.Stacked} />

### In a Dialog

Inside a `Dialog` the stacked large Result is the whole body: no `Header` and no `Footer`. Its title takes the dialog `title` slot, so the dialog is labelled by it automatically.

```jsx
<DialogContainer isOpen={isOpen} onDismiss={close}>
  <Dialog size="S">
    <Content>
      <Result
        size="large"
        layout="stacked"
        status="success"
        title="Payment complete"
        subtitle="Charged $1,234.00 to Visa **** 4242"
        actions={
          <Button type="primary" size="large" onPress={close}>
            Done
          </Button>
        }
      />
    </Content>
  </Dialog>
</DialogContainer>
```

## Accessibility

### Keyboard Navigation

- The component itself is not focusable; the buttons passed through `actions` keep their own keyboard behavior

### Screen Reader Support

- The title renders as an `h2` heading and the subtitle as an `h3`, so the result is reachable through heading navigation
- Inside a `Dialog` without a `Header`, the title takes the dialog's `title` slot and becomes its accessible name

## Best Practices

1. **Do**: Put the buttons in `actions` and keep `children` for content

   ```jsx
   <Result title="Payment failed" actions={<Button>Update card</Button>}>
     <Alert>Nothing was charged.</Alert>
   </Result>
   ```

2. **Don't**: Combine a Result with a dialog `Header`. Both titles would take the dialog `title` slot and share one id

   ```jsx
   <Dialog>
     <Header>
       <Title>Payment</Title>
     </Header>
     <Content>
       <Result size="large" layout="stacked" title="Payment complete" />
     </Content>
   </Dialog>
   ```
