# ItemCard

A card for content with a heading, a body and optional inline actions. It wraps `Item type="card"`, mapping `title` to the heading and `children` to the body. The default theme uses the same neutral surface and border as `Card`; semantic themes add status colors.

## When to Use

- To group content or controls under a heading
- For status messages that need a heading, body and optional actions
- Use [Card](/docs/content-card--docs) when you only need a container, or [Alert](/docs/content-alert--docs) for a concise status message

### Properties

- **`title`** `ReactNode` — Card heading (mapped to Item's `children`)
- **`children`** `ReactNode` — Card body content (mapped to Item's `description`)
- **`theme`** `'default' | 'success' | 'danger' | 'warning' | 'note' | 'current'` (default: `default`) — Neutral surface, semantic status or inherited-color theme
- **`size`** `'xsmall' | 'small' | 'medium' | 'large' | 'xlarge'` (default: `medium`) — Size of the card
- **`icon`** `ReactNode` — Icon displayed before the content
- **`rightIcon`** `ReactNode` — Icon displayed after the content
- **`prefix`** `ReactNode` — Content rendered before the label
- **`suffix`** `ReactNode` — Content rendered after the label
- **`tooltip`** `string | boolean | object` (default: `true`) — Tooltip configuration: string for text, `true` for auto overflow tooltips, or object for advanced config
- **`hotkeys`** `string` — Keyboard shortcut displayed and triggered
- **`isSelected`** `boolean` (default: `false`) — Whether the card shows as selected with a checkmark
- **`isLoading`** `boolean` (default: `false`) — Show loading state, replacing an icon slot with a spinner
- **`actions`** `ReactNode` — Inline action buttons displayed on the right side
- **`autoHideActions`** `boolean` (default: `false`) — When true, actions are hidden by default and shown on hover or focus
- **`preserveActionsSpace`** `boolean` (default: `false`) — Preserve the actions width when hidden (only changes opacity, not layout)
- **`disableActionsFocus`** `boolean` (default: `false`) — Disable focus on action buttons by setting tabIndex to -1
- **`level`** `1 | 2 | 3 | 4 | 5 | 6` (default: `3`) — Heading level for the card title
- **`highlight`** `string` — String to highlight within children text
- **`highlightCaseSensitive`** `boolean` (default: `false`) — Whether highlight matching is case-sensitive

Inherits from [Item](/docs/content-item--docs) (with `type="card"`).

### Styling Properties

#### styles

Inherits styling from `Item`, with `fill="#surface"` and `border="#border"` for the default theme. Semantic themes retain their tinted surfaces and borders. An explicit `variant` retains Item's corresponding variant appearance. Ordinary style props and `styles` override these defaults. ## Variants

### Sizes

- `medium` — Default size suitable for most use cases
- `large` — Larger size for prominent notifications
- `xlarge` — Extra large size for emphasized alerts

### Themes

Use the default theme for grouped content and a semantic theme when color communicates a status:

- `default` — Neutral `#surface` fill and `#border` border
- `success` — Green theme for positive outcomes
- `danger` — Red theme for errors or destructive states
- `warning` — Amber theme for caution
- `note` — Violet theme for informational context

The `current` theme uses the inherited foreground color for its tinted surface and border. See [Item documentation](/docs/content-item--docs) for theme styling.

### With a Close Button

Use `ItemCard.Action` with an accessible name and an `onPress` handler. The application owns dismissal and moves focus to an appropriate control when the card disappears. This example offers a restore button and focuses it after dismissal; restoring the card focuses its close button without moving focus on the initial render.

```jsx
function DismissibleNotice() {
  const [isDismissed, setIsDismissed] = useState(false);
  const focusTarget = useRef(null);
  const didInteract = useRef(false);

  useEffect(() => {
    if (didInteract.current) focusTarget.current?.focus();
  }, [isDismissed]);

  function toggleNotice() {
    didInteract.current = true;
    setIsDismissed((value) => !value);
  }

  return isDismissed ? (
    <Button ref={focusTarget} onPress={toggleNotice}>
      Restore setup notice
    </Button>
  ) : (
    <ItemCard
      title="Setup notice"
      actions={
        <ItemCard.Action
          ref={focusTarget}
          icon={<IconX />}
          aria-label="Dismiss setup notice"
          onPress={toggleNotice}
        />
      }
    >
      Connect a data source to start exploring your data.
    </ItemCard>
  );
}
```

### Rich Body Content

The body accepts React nodes, including labelled controls. Keep the card itself presentational when its body contains interactive elements.

```jsx
<ItemCard title="Notification settings">
  <Space flow="column" gap="1.5x">
    <Text>Choose what to include in scheduled refresh notifications.</Text>
    <Checkbox defaultSelected>Send email notifications</Checkbox>
    <Switch label="Include query details" />
  </Space>
</ItemCard>
```

### Transparent Surface

Use `fill="transparent"` when the surrounding container should supply the surface. The default border still separates the content.

```jsx
<ItemCard title="Details" fill="transparent">
  Content on the surrounding surface.
</ItemCard>
```

### Custom Heading Level

The `level` prop controls the semantic HTML heading tag (h1-h6) for the title. Default is `level={3}` (h3).

```jsx
<ItemCard title="Important Section" icon={<IconInfoCircle />} level={2}>
  This card's title renders as an h2 element.
</ItemCard>
```

## Accessibility

### Keyboard Navigation

- `Tab` - Moves focus through inline actions and controls in the body
- `Space/Enter` - Activates a focused action button
- Dismissal should move focus to an appropriate remaining control

### Screen Reader Support

- Title renders as a semantic heading (h1-h6) via the `level` prop for proper document structure
- Icon-only actions need an accessible name such as `aria-label="Dismiss setup notice"`
- Inherits all accessibility features from `Item`

### ARIA Properties

- `aria-label` - Provides accessible label when no visible label exists

## Best Practices

1. **Do**: Use meaningful titles and body content

   ```jsx
   <ItemCard title="Deployment Complete" icon={<IconCheck />} theme="success">
     Your changes are now live in production.
   </ItemCard>
   ```

   Body text wraps. Long titles remain on one line and show an overflow tooltip by default.

2. **Don't**: Use without a title
   ```jsx
   {/* Prefer using Item type="card" directly if you only need a description */}
   <ItemCard>Body only without a title</ItemCard>
   ```
