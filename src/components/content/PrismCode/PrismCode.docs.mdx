# PrismCode

Syntax-highlighted code block using Prism. Supports multiple languages.

## When to Use

- Documentation code examples
- Displaying code in UI
- Technical content with syntax highlighting

## Properties

- **`code`** `string` (default: `''`) — The code snippet to highlight
- **`language`** `string` (default: `'javascript'`) — Language for syntax highlighting (`javascript`, `typescript`, `json`, `yaml`, `bash`, `sql`, `css`, `html`, etc.)
- **`isWrapped`** `boolean` — Soft-wrap long lines onto multiple lines instead of scrolling them horizontally. Unbreakable runs (URLs, tokens, identifiers) wrap too. Useful for error messages and logs.

### Style Defaults

- `margin` — `0`
- `padding` — `0`
- `overflow` — `auto`
- `scrollbar` — `styled`
- `preset` — `s3` (monospace snippet size)

### Base Properties

Supports [Base properties](/docs/getting-started-base-properties--docs).

## Theme

Syntax colors are driven by a dedicated, scheme-aware palette of `code-*` tokens. Each token uses a different hue so token classes stay visually separable, and every token meets at least **WCAG AA (4.5:1)** contrast against `#surface` in light, dark, and high-contrast schemes (AAA in HC).

| Token | Hue | Used for |
| --- | --- | --- |
| `#code-comment` | gray | comments, prolog, doctype, cdata |
| `#code-punctuation` | muted pink | operators, punctuation |
| `#code-keyword` | pink | keywords, booleans, constants, atrules, HTML/XML tag names (`font-weight: 500` on language keywords) |
| `#code-string` | primary purple | strings, characters, attribute values, URLs |
| `#code-number` | green | numbers, numeric entities |
| `#code-function` | pink | functions, class names, regex, variables |
| `#code-attribute` | cyan | attribute names, properties, selectors, built-ins, keys |

Diff insertion (`+`) and deletion (`-`) intentionally re-use the existing `#success-*` / `#danger-*` ramps — both the line background tint and the foreground color adapt to the active scheme.

## Examples

```jsx
<PrismCode code="const x = 1;" language="javascript" />

<PrismCode
  code={'function hello() {\n  return "world";\n}'}
  language="typescript"
/>
```
