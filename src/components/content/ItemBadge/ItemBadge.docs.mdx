# ItemBadge

A non-interactive badge indicator for list items. Similar to `ItemAction` but without press behavior (cursor: default).

## When to Use

- Status indicators in list items
- Visual badges showing state (selected, loading)
- Non-clickable indicators alongside `ItemAction` buttons

## Properties

- **`icon`** `ReactNode | 'checkmark'` — Icon or checkmark display
- **`type`** `'primary' | 'outline' | 'clear'` (default: `'clear'`) — Visual type. `isSelected` applies brand-tinted fill to `outline` and `clear`.
- **`theme`** `'current' | 'default' | 'danger' | 'success' | 'special'` (default: `'current'`) — Color theme. `current` derives every color from the inherited `currentcolor`, so the badge tracks whatever row hosts it. Name any other theme to have the badge paint itself instead.
- **`isLoading`** `boolean` (default: `false`) — Show loading spinner
- **`isSelected`** `boolean` (default: `false`) — Selected state (for checkmark)
- **`tooltip`** `string | object` — Tooltip content shown on hover for icon-only badges. A string shows tooltip text; an object supports `{ title, ...tooltipProps }` for advanced configuration.

### Accessibility

A badge is never focusable. An icon-only badge with a name — `aria-label`, or a plain-text `tooltip` — is exposed as `role="img"` with that name. When the name is not the tooltip text, the tooltip text also becomes the badge's description (`aria-description`), so screen reader users get it without hovering. Rich tooltip content has no plain text, so it is available on hover only. Pass `role` to use another role.

Supports [Base properties](/docs/getting-started-base-properties--docs).

## Examples

```jsx
<ItemBadge icon="checkmark" isSelected />

<ItemBadge icon={<IconCheck />} theme="success" />

<ItemBadge isLoading />
```
