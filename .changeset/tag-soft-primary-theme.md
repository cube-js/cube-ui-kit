Add a soft brand-purple `Tag` theme: `<Tag theme="primary">` renders the pale card — tinted border, strong colored text — at the primary hue, alongside the existing `default`, `danger`, `success`, `warning` and `note` cards. Previously the brand hue was reachable only through `theme="special"`, which is a solid fill, so designs calling for a soft purple chip had to borrow `note` one hue over. `special` is unchanged and still renders the solid fill.
