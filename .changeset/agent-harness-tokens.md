Ship a harness for coding agents. In projects that use [harnesspm](https://www.npmjs.com/package/@tenphi/harnesspm), agents get a short UI Kit rule, an index of the UI Kit docs, and the harnesses of Tasty 3.19.1 and Glaze 3.1.0, which UI Kit now pins: Tasty's styles rule and docs, with `tasty:styles` set up to load UI Kit's config, and Glaze's colors rule adapted to UI Kit's palette, its docs and its theme skill. `@tenphi/eslint-plugin-tasty` 1.19 is now an optional peer: in a project that installs it, agents also get its `tasty-lint` harness, with a rule to lint the styles they change, a page for every `tasty/*` rule, `tasty-lint:check`, and a hook that lints each file they edit. Once a project trusts `@cube-dev/ui-kit`, agents can run `uikit:tokens`, which looks up palette tokens and their aliases by name, with their values in light, dark and high contrast and their contrast against their base, or on another surface with `--on <token>`. `tasty:styles`, Glaze's tools and the lint tool and hook also need `@tenphi/tasty`, `@tenphi/glaze` and `@tenphi/eslint-plugin-tasty` trusted. The docs now ship as their sources: the Storybook pages in `src/**/*.docs.mdx` and the Modern Form guides next to `ModernForm.docs.mdx`, which harnesspm indexes as they are. The generated `docs/components`, `docs/*.md` and `docs/llms.txt`, and the copies of Tasty's and Glaze's docs in `docs/tasty` and `docs/glaze`, are gone: read Tasty's and Glaze's docs in those packages or on GitHub.
