Ship a harness for coding agents. In projects that use [harnesspm](https://www.npmjs.com/package/@tenphi/harnesspm), agents get a short UI Kit rule, an index of the UI Kit and Tasty docs, Glaze's harness (its colors rule adapted to UI Kit's palette, its docs, its theme skill and tools), and `uikit:tokens`, which looks up palette tokens by name with their values in light, dark and high contrast and their contrast against their base.
