**Breaking:** an input's style props now place and size its outer element: the field wrapper when its chrome renders, the input itself when it is bare. Adding a label no longer moves `width`, `height`, `flex*`, `gridArea`, `margin`, `inset`, `position` or `zIndex` from the field to the control inside it. When style props size a wrapped field, the input stretches to fill it, unless it has a fixed or capped size of its own (`Checkbox` and `Switch` keep their content width, single-line inputs and a vertical `Slider` their height). `styles` still styles the input and `fieldStyles` the wrapper; a style prop wins over `fieldStyles` for the same key, and only style props make the input fill the field.

This applies to every field-level input: the `TextInput` family, `SearchInput`, `ColorInput`, `ComboBox`, `SearchComboBox`, `Select`, `Picker`, `FilterPicker`, `ListBox`, `FilterListBox`, `TagInput`, `Checkbox`, `CheckboxGroup`, `RadioGroup`, `Switch`, the sliders, the date and time inputs and pickers, `FileInput`, `ColorPicker` and `ColorSwatchGroup`. They now take exactly the position and dimension style props (`FieldLayoutStyleProps`, exported). Every other style prop is removed from them: the base, block, color and flow groups, such as `fill`, `color`, `border`, `radius`, `shadow`, `outline`, `padding`, `preset`, `font`, `display`, `hide`, `opacity`, `transition`, `textAlign`, `overflow`, `flow`, `gap`, `place`, `placeItems`, `placeContent`, `align`, `alignItems`, `alignContent`, `justify`, `justifyItems` and `justifyContent` (`placeSelf`, `alignSelf` and `justifySelf` stay). Pass those through `styles`.

Migrating: on a labelled field, check style props that used to size the control. A side-label field's `width` now includes the label column, and `height` includes the label and texts. To size the control alone, use `styles={{ width }}`. A state map on a style prop now resolves against the wrapper on a labelled field, so use media, container or root states there, not input states such as `focused`. `className`, `style`, `qa` and `ref` never move to the wrapper. A `fieldStyles` used only to place or size the field can become style props.

Fixes: `DateInput`, `TimeInput` and `FileInput` now apply their `styles` and style props, which they dropped before. `RangeSlider` forwards `styles`. `fieldProps.mods` adds to the mods a field wrapper computes instead of replacing them, and a `null` in `fieldStyles` or `fieldProps.styles` now resets that key on the wrapper.
