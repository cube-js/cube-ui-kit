`Alert` takes `theme="neutral"`, the gray card of `disabled` with the regular text color, for a note that carries no status, and `size="small"`, which sets `t4` text and `1x` padding for an alert in a dense panel. They replace a `color` set on a disabled alert and a `preset` and `padding` set by hand.
