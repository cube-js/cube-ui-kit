`DataTable` / `ItemTable`: a column's `cellStyles` now go through tasty instead of the cell's inline `style`. Tokens such as `{ color: '#surface-text-soft-2' }`, units, presets and state maps now take effect where they used to be dropped silently, and the column's styles win over the table's default cell paint, column tints and the table-level `cellStyles`. On a `dataType: 'number'` column, a function-form `cellStyles` is now called per cell and merged over the tabular figures; before, the numeric default replaced it. Values are now read as tasty rather than CSS, so check CSS-shaped ones: a side property such as `paddingLeft: 24` or `marginTop: 8` becomes the full shorthand with the other sides at 0 (use the CSS longhand with a unit, `paddingInlineStart: '24px'`, to set one side); a bare number takes a unit on tasty's own properties (`lineHeight: 1.2` becomes `1.2px`, pass `'1.2'` for a unitless value) but stays unitless, and so invalid, on plain CSS ones (`borderRadius: 4`, pass `'4px'` or use `radius`); a plain color name inside `border` or `outline` is dropped (`'1px solid red'`, write `'1px solid #red'`); and `textOverflow: 'ellipsis'` also sets `overflow: hidden` and `white-space: nowrap`.
