`Result` takes `layout="tight"` for a result in a box that clips, such as a dashboard tile. The icon, title, content and actions are spaced by `gap` alone (`1x` unless you set it), with no padding and no room around the icon, so the actions stay inside the box. It replaces styles that zeroed the `Icon` padding and the `Content` and `Actions` margins.
