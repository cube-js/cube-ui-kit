Update Tasty to 3.10.0 (from 3.9.9). Production builds no longer turn on Tasty's development diagnostics and debug instrumentation by default. An `animation` keeps the case of a camelCase keyframe name and finds a name written after `steps(n, end)`. Global styles set with `useGlobalStyles` apply `@starting` values inside `@starting-style`, emit the local `@keyframes` they use, and give every selector in a list its states.
